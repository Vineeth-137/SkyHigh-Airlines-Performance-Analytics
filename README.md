
# ✈️ SkyHigh Airlines Performance Analytics Dashboard

An interactive **Power BI Business Intelligence Dashboard** developed to analyze airline operational performance, passenger trends, airport traffic, delays, and revenue insights. The project leverages **Power BI, DAX, Power Query, and data modeling** to transform raw airline datasets into meaningful business insights.

---

# 📖 Project Overview

This dashboard helps airline management monitor key performance indicators (KPIs), identify operational bottlenecks, and make data-driven decisions through interactive visualizations.

The dashboard provides insights into:

- Flight Performance
- Passenger Trends
- Revenue Analysis
- Airport Performance
- Operational Efficiency
- Executive KPI Monitoring

---

# 🚀 Features

- Interactive Power BI Dashboard

# 📂 Dataset

The project uses multiple datasets:

- Airline_Airports.csv
- Airline_Flights.csv
- Airline_Passengers.csv
- Airline_Revenue.csv

These datasets were cleaned, transformed, and modeled using Power Query before creating interactive dashboards.
